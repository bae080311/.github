# .github

`bae080311` 계정의 **기본 이슈·PR 템플릿**. 자체 템플릿이 없는 모든 레포가 이걸 물려받는다
(public·private 둘 다). 레포에 같은 종류의 파일이 있으면 그쪽이 이긴다.

> 이 레포는 GitHub 요구사항상 **public 이어야** 기본값으로 동작한다.
> 그래서 프로젝트 고유 정보(도메인 체크박스, 내부 URL, 검증 명령)를 넣지 않는다.

| 파일 | 무엇 |
| --- | --- |
| `ISSUE_TEMPLATE/bug_report.md` | 버그 |
| `ISSUE_TEMPLATE/task.md` | 개발 작업 |
| `ISSUE_TEMPLATE/harness.md` | `.claude` 하네스 표준 정리 |
| `pull_request_template.md` | PR |

하네스 표준의 SSOT 는 [claude-config](https://github.com/bae080311/claude-config) 다.
